## 回归重点

- 500 / 501 个 Unicode 码点、空白正文、混合媒体、5 / 6 张图片、15 秒视频及 60 秒语音边界；服务端拒绝损坏、伪装、超时长媒体。
- 原始待传文件独立计入手机配额，服务器预留容量计入账号额度；容量不足明确失败，不自动删内容。
- 多项离线完成、SQLite 重开恢复、稳定 command / record ID、原始 wire 持久化、丢响应后的只读回执恢复及删除墓碑。
- 双设备冲突保留有效记录和暂停草稿；已经打开的编辑器绑定原分支，即使两设备正在同一个活动也不能改写云端草稿。
- 移动网络授权只覆盖点击时队列，跨十命令批次仍有效，不包含上传期间新建的记录；上传不阻塞短事务草稿和离线完成。
- 前后台共享租约、过期任务不能继续提交、切账号固定凭据、各账号与服务地址隔离、登录过期保留本机内容。
- SQLite 双连接 160 次并发写入/读取/租约操作、真实锁争用的异步有界重试、开库与关闭竞争、并发仓储关闭和后台任务收尾。故意损坏的临时数据库用例会输出预期的 SQLite 错误日志，断言已通过。
- 私有媒体读取、缩略图和 Range 鉴权；只有成功记录回执后清理待传源。取消编辑、放弃录音和移除未绑定附件不影响原记录。
- 明确失败的待传记录可由用户确认改成纯文字重试。已有 wire 必须先证明尚未提交；原 ID / 顺序不变，原文件仍保留至记录回执，不会自动降级或删除。
- 注册、记录、更换活动、搜索分页、在线编辑、图片分享默认不勾选、小屏、大字号与键盘回归。

## 必须补做的 Android 实机验收

1. 配置本地 API 并通过 `adb reverse` 连接，使用测试账号；核对安装包签名后安装，不清除旧数据。
2. 相册选择旋转照片、5 张图片和 15 秒视频，检查方向、缩略图、视频拖动、重新选择超长视频；拒绝权限后能够重试。
3. 录音试听、重录、到时停止、切后台、系统电话/音频中断；核对恢复时保留可用片段且没有后台收音。
4. 系统相册期间结束应用进程，再打开原账号/原分支恢复；切到其他账号不能接管结果。
5. 离线完成多项，重启应用、重启手机，切换 WiFi/移动网络，验证授权批次与前后台任务；系统延迟或强制停止不承诺立即上传。
6. 真实存储空间不足、录音/媒体编解码硬件差异，以及两台设备同时编辑与删除；分享系统面板仅包含预览确认的内容。

这些检查尚未在实体手机执行。桌面 HTTP 故障注入不等同于蜂窝基带切网，SQLite 重开不等同于 Android 重启，Widget 权限替身不等同于系统权限弹窗。
